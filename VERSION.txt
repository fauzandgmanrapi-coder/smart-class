SMART CLASS ONLINE v2026-10-28-v9.0.5
====================================

Perbaikan MIKRO dari v2026-10-28-v9.0.4: jawaban Asisten
Smart Class kini tampil bersih sebagai teks polos —
tanda markdown (terutama **) dihilangkan. Menggantikan
paket v9.0.4. TIDAK ada migrasi SQL baru — folder
supabase/ identik dengan v9/v8.

Latar: panel chat merender jawaban sebagai teks polos
(pre-wrap), sehingga format tebal markdown dari model
tampil mentah sebagai **kata**. User meminta tanda itu
dihilangkan agar jawaban mudah dibaca.

Dua lapis perbaikan di v9.0.5:

1) src/app/api/asisten/route.ts — fungsi pembersih
   bersihkanMarkdown diterapkan pada string balasan
   AKHIR sebelum dikembalikan sebagai {reply}:
   - Pasangan tebal /\*\*([^*]+)\*\*/g -> "$1"
     (isi dipertahankan, tandanya dibuang).
   - Sisa "**" yang tak berpasangan -> dibuang.
   - Bullet di awal baris /^\s*\*\s+/gm -> "• ".
   - Judul markdown di awal baris /^#{1,6}\s+/gm -> "".
   - Isi lain TIDAK diubah: satu "*" tunggal di tengah
     baris (mis. "Harga 2 * 3") tetap utuh.
   Terverifikasi uji unit Node: contoh
   "**Kartu Statistik:** penting / * item satu /
   ## Judul / Harga 2 * 3" menjadi
   "Kartu Statistik: penting / • item satu / Judul /
   Harga 2 * 3" persis seperti diharapkan.
   Pesan error/diagnostik, logika rantai model,
   validasi, thinkingConfig, dan anggaran waktu TIDAK
   berubah.

2) src/lib/asisten-pengetahuan.ts — aturan gaya baru
   (aturan 8) di SYSTEM_PROMPT_ASISTEN: model diminta
   menulis TEKS POLOS tanpa markdown — tidak memakai
   ** untuk menebal, tidak memakai # untuk judul;
   daftar memakai awalan "• " atau penomoran biasa.
   Ini mengurangi tanda dari sumbernya; pembersih di
   route adalah jaminan akhirnya.

Urutan deploy (dari v9.0.4 — TANPA langkah migrasi SQL):
1) Ekstrak paket ke folder BARU, upload seluruh isinya ke
   GitHub (timpa file lama).
2) Env GEMINI_API_KEY di Vercel TIDAK perlu diubah —
   pastikan tetap terpasang (semua environment, TANPA
   NEXT_PUBLIC_). Kunci bersifat rahasia — jangan
   dibagikan, jangan masuk GitHub/chat.
3) Redeploy, tunggu selesai, lalu Ctrl+F5 di aplikasi.
4) Login -> klik tombol chat -> ajukan pertanyaan;
   jawaban kini tampil sebagai teks polos tanpa tanda
   ** lagi.
