SMART CLASS ONLINE v2026-10-28-v9.0.1
====================================

Perbaikan MIKRO diagnostik dari v2026-10-28-v9: route
/api/asisten kini meneruskan penyebab kegagalan panggilan
Gemini agar bisa dibaca persis, bukan lagi 502 generik saja.
Paket ini MENGGANTIKAN paket v9. TIDAK ada migrasi SQL baru —
folder supabase/ identik dengan v9/v8.

Yang berubah di v9.0.1 (HANYA src/app/api/asisten/route.ts):
- Respons Gemini tidak OK -> route membaca error Google
  ({error:{code,status,message}}), mencatat satu baris ringkas
  "asisten-upstream" + status HTTP + error.status + pesan
  (dipotong maks 200 karakter) via console.error ke log
  server, dan membalas klien:
  502 {error:"upstream", upstream_status:<angka HTTP>,
       upstream_code:<error.status Google atau "">}
- fetch-nya sendiri gagal (jaringan/timeout) -> dicatat
  "asisten-fetch-failed" + nama/pesan error (maks 200
  karakter), dan membalas:
  502 {error:"upstream", upstream_status:0,
       upstream_code:"FETCH_FAILED"}
- Kunci API TIDAK pernah ditulis ke log maupun respons.
- Perilaku lain identik v9: payload tidak valid -> 400,
  kunci belum dipasang -> 503 {error:"not_configured"},
  sukses -> {reply}. UI AsistenChat.tsx tidak berubah
  (menampilkan pesan generik yang sama untuk semua 502).
- package.json -> versi 1.6.1.

Untuk membaca penyebab kegagalan setelah deploy: buka log
fungsi di Vercel (Deployments -> deployment aktif -> Logs /
Functions) lalu ajukan satu pertanyaan ke Asisten; baris
"asisten-upstream" menunjukkan status & kode Google-nya,
mis. 400 API_KEY_INVALID (kunci salah), 404 (model tidak
ditemukan), 429 RESOURCE_EXHAUSTED (kuota habis),
403 PERMISSION_DENIED (API belum aktif/izin).

Seluruh isi v9 tetap berlaku (Asisten Smart Class: tombol chat
melayang setelah login, POST /api/asisten -> Gemini REST
gemini-2.5-flash via env server GEMINI_API_KEY tanpa
NEXT_PUBLIC_, basis pengetahuan asisten-pengetahuan.ts dari
Manual Book v5 + fitur v8) dan seluruh isi v8.2.1 di bawahnya
(multi-akun dua peran, Dashboard Admin, Monitoring Dosen,
halaman mahasiswa, pengumpulan online, tanda tangan laporan,
grafik dashboard, perbaikan fmtTanggalWaktu).

Urutan deploy (dari v9 — TANPA langkah migrasi SQL):
1) Upload seluruh isi paket ke GitHub (timpa file lama).
2) Pastikan env GEMINI_API_KEY sudah terpasang di Vercel
   (Settings -> Environment Variables, semua environment,
   TANPA NEXT_PUBLIC_). Kunci bersifat rahasia — jangan
   dibagikan, jangan masuk GitHub/chat.
3) Redeploy, tunggu selesai, lalu Ctrl+F5 di aplikasi.
4) Login -> klik tombol chat -> ajukan pertanyaan. Bila
   masih gagal, respons 502 kini memuat upstream_status &
   upstream_code, dan log server memuat baris
   "asisten-upstream" — laporkan kedua nilai itu untuk
   diagnosis lanjutan.
