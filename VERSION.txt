chatbot AI panduan penggunaan aplikasi di dalam aplikasi, untuk
pengguna yang sudah login (dosen & admin). Paket ini

skema/RLS/fungsi publik/Edge Function tidak berubah, folder
supabase/ identik dengan v8/v8.2.1.

Yang baru di v9:

  kedua peran) membuka panel "Asisten Smart Class — Panduan

  SDK/dependensi baru). Kunci API dibaca dari env server

  ramah "asisten belum diaktifkan"; payload tidak valid -> 400

  Mahasiswa & QR, Pengumpulan Tugas Online, Rekap & Laporan,
  Backup/Restore/Reset, peran & isolasi data v8, Dashboard

- System prompt membatasi asisten: HANYA menjawab penggunaan

Urutan deploy (dari v8.2.1 — TANPA langkah migrasi SQL):
1) Upload seluruh isi paket ke GitHub (timpa file lama).
2) Buat kunci API Gemini di Google AI Studio
   (aistudio.google.com -> Get API key -> Create API key).
3) Di Vercel: Settings -> Environment Variables -> tambahkan
   GEMINI_API_KEY (semua environment, TANPA NEXT_PUBLIC_).
   Kunci bersifat rahasia — jangan dibagikan, jangan masuk
   GitHub/chat.
4) Redeploy, tunggu selesai, lalu Ctrl+F5 di aplikasi.
5) Login -> klik tombol chat pojok kanan bawah -> uji chip
   "Cara export nilai ke SIAKAD?" (jawaban harus menyebut menu
   Penilaian dan prasyarat total bobot 100%).
   (Tanpa langkah 2-3, panel tetap tampil tetapi menjawab
   bahwa asisten belum diaktifkan.)
