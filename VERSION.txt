SMART CLASS ONLINE v2026-10-28-v9.0.2
====================================

Perbaikan MIKRO dari v2026-10-28-v9.0.1: route /api/asisten
kini mencoba beberapa model Gemini BERURUTAN (rantai model
cadangan). Diagnosis live v9.0.1 terbukti 404 NOT_FOUND:
API key user VALID (key salah akan memberi 400) dan API
Gemini aktif, tetapi model "gemini-2.5-flash" tidak tersedia
untuk key/proyek user — obatnya mencoba model lain sampai
ada yang berhasil.
Paket ini MENGGANTIKAN paket v9.0.1. TIDAK ada migrasi SQL
baru — folder supabase/ identik dengan v9/v8.

Yang berubah di v9.0.2 (HANYA src/app/api/asisten/route.ts):
- Konstanta DAFTAR_MODEL dicoba satu per satu:
  "gemini-2.5-flash" -> "gemini-flash-latest" ->
  "gemini-2.5-flash-lite" -> "gemini-2.0-flash".
  Isi permintaan identik untuk tiap model (systemInstruction,
  contents, generationConfig), kunci dari env server
  GEMINI_API_KEY, timeout 20 detik per percobaan.
- Respons OK dari model mana pun -> langsung balas {reply}.
- Respons 404 -> dicatat "asisten-upstream" + nama model +
  status + kode Google (pola v9.0.1), lalu LANJUT ke model
  berikutnya.
- Respons error SELAIN 404 (400 key tidak valid, 403, 429
  kuota, dst) -> TIDAK lanjut ke model lain; langsung balas
  502 diagnostik pola v9.0.1 (upstream_status +
  upstream_code) untuk error itu.
- fetch gagal (jaringan/timeout) -> langsung 502
  {error:"upstream", upstream_status:0,
  upstream_code:"FETCH_FAILED"} seperti v9.0.1.
- Bila SEMUA model menjawab 404 -> balas 502 dengan
  upstream_status/upstream_code dari respons TERAKHIR
  (404 NOT_FOUND), sama seperti diagnosis v9.0.1.
- Kunci API TIDAK pernah ditulis ke log maupun respons.
- Perilaku lain identik: payload tidak valid -> 400, kunci
  belum dipasang -> 503 {error:"not_configured"}. UI
  AsistenChat.tsx tidak berubah.
- package.json -> versi 1.6.2.

1) Ekstrak paket ke folder BARU, upload seluruh isinya ke
   GitHub (timpa file lama).
2) Env GEMINI_API_KEY di Vercel TIDAK perlu diubah —
   pastikan tetap terpasang (semua environment, TANPA
   NEXT_PUBLIC_). Kunci bersifat rahasia — jangan
   dibagikan, jangan masuk GitHub/chat.
3) Redeploy, tunggu selesai, lalu Ctrl+F5 di aplikasi.
4) Login -> klik tombol chat -> ajukan pertanyaan;
   asisten kini memakai model pertama yang tersedia.
