SMART CLASS ONLINE v2026-10-27-v8.2.1
====================================

Pembaruan MIKRO dari v2026-10-27-v8.2: perbaikan tampilan
"Invalid Date" pada Monitoring Dosen. Paket ini MENGGANTIKAN
paket v8.2 (jalur deploy tetap v8 -> v8.2.1). Murni perbaikan
antarmuka (frontend) — TIDAK ada migrasi SQL baru, skema/RLS/
fungsi publik tidak berubah, format penyimpanan data tidak
diubah sama sekali.

Yang diperbaiki di v8.2.1:
- Di Monitoring Dosen -> detail kelas -> bagian Tugas ->
  daftar "Pengumpulan Mahasiswa", kolom Waktu Kumpul untuk
  pengumpulan online sebelumnya tampil "Invalid Date".
  Penyebabnya: nilai waktu_kumpul pengumpulan online
  tersimpan sebagai teks tampilan lokal (dari RPC
  pengumpulan online v5) yang tidak bisa diolah
  new Date(...), sedangkan baris manual tersimpan ISO.
- Perbaikan: helper aman fmtTanggalWaktu dipakai untuk
  kolom Waktu Kumpul dan kolom Deadline tugas di dalam blok
  Monitoring. Bila nilai valid -> diformat id-ID seperti
  sebelumnya; bila tidak bisa diolah -> teks aslinya
  ditampilkan apa adanya (persis seperti tampilan sisi
  dosen yang selama ini terbaca normal); bila kosong -> "-".
- Pemformatan di luar blok Monitoring TIDAK diubah;
  pengalaman peran dosen tidak berubah sama sekali.
- package.json -> versi 1.5.3.

Seluruh isi v8.2 tetap berlaku di v8.2.1:
- Menu admin "Monitoring Dosen" (grup menu admin, di antara
  Dashboard Admin dan Manajemen Akun Dosen). Hanya tampil
  untuk akun berperan admin.
- Daftar dosen dengan ringkasan per dosen: jumlah kelas,
  pertemuan terlaksana (status Selesai/Berlangsung) dari
  total pertemuan, rata-rata % kehadiran, jumlah materi,
  jumlah tugas.
- Drill-down per dosen -> daftar kelasnya -> detail kelas
  HANYA-LIHAT berisi: (a) Pertemuan: tanggal, jam, topik,
  status; (b) Materi: judul, pertemuan terkait, deskripsi,
  tautan file; (c) Tugas: judul, deadline, bobot, jumlah
  pengumpulan beserta rincian statusnya + daftar pengumpulan
  mahasiswa; (d) Mahasiswa: daftar peserta aktif kelas;
  (e) Rekap Kehadiran per mahasiswa; (f) Rekap Nilai per
  mahasiswa per komponen + nilai akhir & huruf — hanya bila
  total bobot komponen kelas tepat 100%.
- Data dimuat sekali oleh loadAdmin() lalu diagregasi di
  memori — tanpa query per baris.
- File supabase/ tidak berubah sama sekali dari v8/v8.1/v8.2.

Urutan deploy (dari v8 / v8.2 — TANPA langkah migrasi SQL):
1) Upload seluruh isi paket ke GitHub (timpa file lama).
2) Tunggu deploy Vercel selesai, lalu Ctrl+F5 di aplikasi.
3) Login sebagai admin -> Monitoring Dosen -> buka satu
   dosen dan satu kelas -> pada bagian Tugas pastikan kolom
   Waktu Kumpul daftar Pengumpulan Mahasiswa tidak lagi
   menampilkan "Invalid Date" (baris pengumpulan online
   menampilkan teks waktu aslinya).
   (Bila tampilannya belum berubah, bundle lama masih
   tersaji — uji di jendela privat/incognito.)
