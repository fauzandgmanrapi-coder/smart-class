SMART CLASS ONLINE v2026-10-26-v5
==================================

Fitur baru dari v2026-10-26-v4: PENGUMPULAN TUGAS ONLINE lewat
Halaman Mahasiswa (link publik per kelas).
Marker self-check: baris pertama file ini persis
"SMART CLASS ONLINE v2026-10-26-v5", dan di
src/app/m/[token]/page.tsx ada teks "Kumpulkan Tugas".

Cara kerja fitur baru:
- Setiap tugas di halaman publik kini punya tombol
  "📤 Kumpulkan Tugas" yang membuka formulir: NIM, Nama Lengkap,
  Tautan File (Google Drive, dll.), Nama File (opsional), dan
  Catatan (opsional).
- Tanpa login — sebagai gantinya server memeriksa NIM + Nama
  harus cocok dengan anggota AKTIF kelas pemilik link (fungsi
  kumpul_tugas_mahasiswa). Daftar mahasiswa TIDAK pernah
  ditampilkan di halaman publik.
- Mengumpulkan ulang dengan NIM yang sama menimpa kiriman
  sebelumnya, KECUALI yang sudah dinilai dosen (ditolak).
- Lewat deadline -> status otomatis "Terlambat" (deadline
  ditafsirkan sebagai waktu Asia/Makassar/WITA).
- Hasilnya masuk tabel pengumpulan_tugas yang sama: dosen
  melihatnya di Materi & Tugas > Pengumpulan lengkap dengan
  waktu kirim ("Dikumpulkan: ..."), lalu menilai seperti biasa.

WAJIB: jalankan migrasi supabase/migrasi-v5-pengumpulan-online.sql
di SQL Editor proyek Supabase "smart-class" (satu kali, aman
diulang). Migrasi menambah fungsi kumpul_tugas_mahasiswa dan
memperbarui halaman_mahasiswa agar menyertakan id tugas.

Paket ini juga memuat perbaikan v4 (ikon tanggal/jam kontras di
globals.css) dan seluruh perbaikan v3 + fitur v2 — bila Anda
melompat dari v3, cukup ikuti langkah di bawah ini.
