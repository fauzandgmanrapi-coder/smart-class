SMART CLASS ONLINE v2026-10-27-v8.2
====================================

Pembaruan dari v2026-10-27-v8.1: DAFTAR PENGUMPULAN MAHASISWA
di Monitoring Dosen. Paket ini MENGGANTIKAN paket v8.1 (yang
belum pernah di-deploy) — dari v8 langsung naik ke v8.2.
Murni tambahan antarmuka (frontend) — TIDAK ada migrasi SQL
baru, skema/RLS/fungsi publik tidak berubah dari v8.

Yang baru di v8.2:
- Pada Monitoring Dosen -> detail kelas -> bagian Tugas,
  setiap tugas kini menampilkan daftar "Pengumpulan
  Mahasiswa" tepat di bawah baris tugasnya: nama mahasiswa
  + NIM, waktu kumpul, status pengumpulan (Belum Dinilai /
  Sudah Dinilai / Terlambat), nilai bila sudah dinilai, dan
  tautan file kiriman mahasiswa (klik untuk membuka /
  mengunduh file-nya). Bila belum ada kiriman untuk tugas
  itu, tertulis "Belum ada pengumpulan."
- Data pengumpulan memang sudah dimuat loadAdmin() sejak
  v8.1; v8.2 hanya menampilkan baris-barisnya per mahasiswa.
- Tetap 100% HANYA-LIHAT: daftar ini tidak menambah tombol,
  input, atau aksi tulis apa pun; badge "Mode Pantau —
  Hanya Lihat" tetap tampil di setiap level Monitoring.
- package.json -> versi 1.5.2.

Seluruh isi v8.1 tetap berlaku di v8.2:
- Menu admin "Monitoring Dosen" (grup menu admin, di antara
  Dashboard Admin dan Manajemen Akun Dosen). Hanya tampil
  untuk akun berperan admin.
- Daftar dosen dengan ringkasan per dosen: jumlah kelas,
  pertemuan terlaksana (status Selesai/Berlangsung) dari
  total pertemuan, rata-rata % kehadiran, jumlah materi,
  jumlah tugas.
- Drill-down per dosen -> daftar kelasnya -> detail kelas
  HANYA-LIHAT berisi: (a) Pertemuan: tanggal, jam, topik,
  status; (b) Materi: judul, pertemuan terkait, deskripsi,
  tautan file; (c) Tugas: judul, deadline, bobot, jumlah
  pengumpulan beserta rincian statusnya + daftar pengumpulan
  mahasiswa (baru di v8.2); (d) Mahasiswa: daftar peserta
  aktif kelas; (e) Rekap Kehadiran per mahasiswa; (f) Rekap
  Nilai per mahasiswa per komponen + nilai akhir & huruf —
  hanya bila total bobot komponen kelas tepat 100%.
- Data dimuat sekali oleh loadAdmin() lalu diagregasi di
  memori — tanpa query per baris.
- Pengalaman peran dosen tidak berubah sama sekali.
- File supabase/ tidak berubah sama sekali dari v8/v8.1.

Urutan deploy (dari v8 — TANPA langkah migrasi SQL):
1) Upload seluruh isi paket ke GitHub (timpa file lama).
2) Tunggu deploy Vercel selesai, lalu Ctrl+F5 di aplikasi.
3) Login sebagai admin -> menu "Monitoring Dosen" harus
   muncul; buka satu dosen dan satu kelas, lalu pada bagian
   Tugas pastikan daftar Pengumpulan Mahasiswa tampil di
   bawah setiap tugas tanpa tombol edit apa pun.
   (Bila menu belum muncul, bundle lama masih tersaji —
   uji di jendela privat/incognito.)
