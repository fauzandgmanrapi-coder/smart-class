Perbaikan di v3:
1. Export SIAKAD corrupt (bug paling serius): akar masalahnya satu
   karakter "/" yang nyasar di xl/workbook.xml saat kode menyetel
   fullCalcOnLoad pada tag <calcPr ... /> yang self-closing, sehingga
   workbook.xml tidak valid dan Excel menolak membuka file. Diperbaiki
   di src/lib/siakad.ts (updateCalcOnLoad) dan SUDAH DIUJI lokal
   dengan template PAI asli + 11 data contoh: semua XML valid, sheet
   SM 3 terbaca utuh, file lolos dibuka/diubah oleh LibreOffice.
   Data nilai pada export lama sebenarnya sudah benar — yang rusak
   hanya workbook.xml-nya.
2. Keterangan absensi: tabel Isi Absensi kini punya kolom
   "Keterangan" per mahasiswa (mis. alasan Izin/Sakit), tersimpan ke
   database dan tampil lagi saat absensi dibuka kembali.
3. Kontras ikon kalender/jam: ditambah color-scheme terang + styling
   indikator pemilih tanggal/jam di globals.css — ikon tidak lagi
   putih-di-atas-putih pada Windows/Chrome mode gelap.
4. Halaman Mahasiswa (dari v2): tombol "Bagikan" sebenarnya sudah
   live sejak v2 — bila belum terlihat, itu cache tab browser lama;
   tekan Ctrl+F5 setelah deploy.
