SMART CLASS ONLINE v2026-10-27-v8
==================================

Pembaruan BESAR dari v2026-10-26-v7: MULTI-AKUN DUA PERAN.
Aplikasi tidak lagi memakai satu dataset bersama untuk semua
akun login (desain lama menyebabkan profil dosen bisa tertimpa
saat akun kedua dipakai bersamaan — insiden 27 Okt 2026).

Dua peran akun:
- DOSEN: setiap akun hanya melihat & mengubah data miliknya
  sendiri (kolom owner_id di semua tabel + RLS per pemilik).
  Konsep "dosen aktif" global DIHAPUS; konteks = profil yang
  tertaut ke akun sendiri. Kelas aktif & tahun aktif per akun.
- ADMIN (Rektor/Admin kampus): Dashboard Admin berisi agregat
  lintas dosen (jumlah dosen, kelas aktif, mahasiswa, rata-rata
  kehadiran, distribusi nilai huruf agregat, ringkasan per dosen)
  + menu Manajemen Akun Dosen (buat akun, reset password,
  nonaktifkan/aktifkan, lepas/tautkan profil) lewat Edge Function
  "create-lecturer-account". Admin HANYA membaca data dosen —
  tidak bisa menulis tabel kerja dosen.

Yang berubah:
- supabase/migrasi-v8-multi-akun.sql (BARU, WAJIB dijalankan):
  owner_id + backfill ke akun nurfauzan79@gmail.com, profiles
  diperluas (role, dosen_id, aktif), RLS ditulis ulang, unik per
  pemilik, fungsi publik Halaman Mahasiswa & pengumpulan tugas
  disesuaikan (tetap berfungsi untuk anon lewat token).
- supabase/functions/create-lecturer-account/index.ts (BARU):
  Edge Function pengelolaan akun dosen (service role di server).
- supabase/schema.sql diselaraskan ke bentuk akhir v8.
- src/components/SmartClassApp.tsx: pemuatan profil akun + peran,
  konteks per akun, menu & layar Admin, backup/restore hanya
  data sendiri (backup lama tetap bisa dipulihkan), versi.
- src/lib/types.ts: tipe ProfileAkun, AkunDosen, owner_id.
- src/app/globals.css + section Rekap: PERBAIKAN CETAK — saat
  mencetak Rekap & Laporan (tombol Cetak maupun Ctrl+P), yang
  tercetak HANYA dokumen laporan formal. Kartu pemilih laporan,
  tombol Pratinjau, judul/meta view, tabel pratinjau layar, dan
  judul modal kini tersembunyi saat print (sebelumnya ikut
  tercetak menjadi halaman pertama PDF). Blok tanda tangan v7
  di dokumen formal tidak berubah.
- package.json -> versi 1.5.0.

Semua fitur v2-v7 tetap bekerja untuk peran dosen: 11 menu,
Halaman Mahasiswa + QR, pengumpulan tugas online, Export Nilai
SIAKAD, grafik dashboard, tanda tangan laporan, backup/restore
JSON, reset semester.

Urutan deploy (ringkas — lengkapnya di README & panduan):
1) Export Backup JSON dari aplikasi lama.
2) Jalankan migrasi-v8-multi-akun.sql di Supabase SQL Editor.
3) Deploy Edge Function create-lecturer-account.
4) Upload seluruh isi paket ke GitHub, tunggu Vercel, Ctrl+F5.
5) (Opsional) tetapkan admin pertama lewat potongan SQL di
   akhir file migrasi.
6) Verifikasi dua akun (dosen & admin).
